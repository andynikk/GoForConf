# GoForConf

GoForConf помогает разработчикам, аналитикам и специалистам поддержки разбираться в конфигурациях 1С. Через MCP ИИ-помощник может найти нужный код, изучить метаданные и проследить вызовы. Это пригодится, когда нужно понять, почему срабатывает обработчик, откуда заполняется реквизит, что меняет расширение или какие процедуры затронет доработка.

Для анализа GoForConf читает подготовленный SQLite-снимок конфигурации. Для чтения текущих записей из справочников, документов и регистров администратор отдельно подключает расширение `GoForConfData.cfe` к информационной базе и публикует его HTTP-сервис. [Настройка доступа к живой 1С](docs/live-1c.md)

[Скачать готовый пример для Windows x64](https://github.com/andynikk/GoForConf/releases/latest) · [Подключить MCP-клиент](examples/mcp-client/README.md)

## Что умеет GoForConf

| Задача | Возможности | Примеры MCP-инструментов |
| --- | --- | --- |
| Найти код и прочитать процедуру | Полнотекстовый поиск и поиск по маске в BSL, поиск в XML метаданных, получение текста процедуры по её ID | `search_code_fts`, `search_xml_fts`, `get_procedure_source` |
| Понять устройство объекта | Состав объекта, модули, формы, точки входа, связи документов и ввод на основании | `get_metadata_object`, `get_object_forms`, `get_object_modules`, `get_object_entry_points`, `get_based_on`, `get_basis_for` |
| Проследить выполнение | Вызовы из процедуры, места её вызова и обратные цепочки по связям, сохранённым в снимке | `trace_procedure`, `find_callers`, `trace_callers` |
| Исследовать поведение | Поиск точек входа, сбор фрагментов кода и связей, сводка с фактами, предположениями и следующими проверками | `get_action_evidence`, `investigate_summary`, `investigate_deep` |
| Проверить API платформы | Поиск типов, методов, свойств и таблиц языка запросов по материалам синтакс-помощника, если они включены в снимок | `search_syntax_helper`, `get_syntax_type`, `validate_syntax_member`, `get_syntax_table` |
| Проверить текущее состояние 1С | Описание источника данных и ограниченные запросы на чтение через `GoForConfData.cfe`. Можно связать проверку с исследованием кода | `describe_data_source`, `execute_data_query`, `execute_data_query_text`, `investigate_with_data` |
| Найти код по смыслу или прочитать задачу Jira | Векторный поиск по подготовленным данным и чтение задачи Jira при настройке соответствующих интеграций | `semantic_search`, `get_jira_issue` |

## Как это устроено

```text
MCP-клиент ⇄ stdio / JSON-RPC ⇄ goforconf-mcp ⇄ HTTP ⇄ goforconf-reader
                                                        ├─ SQLite-снимок конфигурации
                                                        └─ HTTPS → GoForConfData → живая 1С (по настройке)
```

`goforconf-reader` открывает существующий SQLite-снимок в режиме чтения и предоставляет HTTP API. `goforconf-mcp` запускается MCP-клиентом и передаёт запросы в reader. MCP (Model Context Protocol) даёт ИИ-помощнику доступ к этим инструментам. Подготовку и обновление снимка выполняет отдельный индексатор. Reader показывает код, метаданные и расширения в том виде, в котором они попали в снимок. Через `GoForConfData` он может дополнительно читать текущие записи из конкретной информационной базы с правами сервисного пользователя 1С.

## Быстрый запуск в Windows x64

1. Скачайте ZIP для Windows x64 со [страницы релизов](https://github.com/andynikk/GoForConf/releases/latest), распакуйте его и запустите `examples\demo-snapshot\start-reader.bat`. Готовые программы и демонстрационный SQLite-снимок уже в комплекте.
2. Откройте PowerShell и проверьте HTTP API. Ответы должны содержать `ok`, `HelloDemo` и `Catalog.DemoItems` соответственно.

   ```powershell
   Invoke-RestMethod 'http://127.0.0.1:8088/health'
   (Invoke-RestMethod 'http://127.0.0.1:8088/procedures/search?q=HelloDemo').items
   (Invoke-RestMethod 'http://127.0.0.1:8088/metadata/object?kind=Catalog&name=DemoItems').object
   ```

3. Добавьте в настройки инструмента с поддержкой MCP запись `goforconf-demo` из `examples/mcp-client/mcp-servers.example.json`. Укажите фактические пути к `goforconf-mcp.exe` и `client.json`. Транспорт — `stdio`. [Пошаговая настройка и проверка из PowerShell](examples/mcp-client/README.md)
4. Для остановки нажмите `Ctrl+C` в окне reader.

Попробуйте написать в MCP-клиенте «Найди `HelloDemo` в снимке и покажи, в каком модуле он найден. Затем опиши объект `Catalog.DemoItems`». Этому соответствуют вызовы `search_code_fts` с `{"q":"HelloDemo"}` и `get_metadata_object` с `{"kind":"Catalog","name":"DemoItems"}`.

Демонстрационный снимок содержит один вымышленный объект метаданных и одну запись поиска процедуры. Этого достаточно, чтобы проверить соединение и посмотреть формат результатов без 1С, Jira и сервиса эмбеддингов. Для исследования реальной конфигурации подключите её снимок.

## Подключение своего снимка

Возьмите подготовленный SQLite-снимок, совместимый с reader. Его можно запросить у администратора, который ведёт индекс вашей конфигурации. Если нужно анализировать изменения расширений, убедитесь, что в снимок попали нужные версии основной конфигурации и активных расширений. После обновления конфигурации для актуального анализа понадобится свежий снимок.

Рядом с `goforconf-reader.exe` создайте локальный `config.local.json`. В примере путь к снимку абсолютный. Относительный `databasePath` считается от рабочего каталога reader. `httpAccessFile` должен быть абсолютным локальным путём.

```json
{
  "databasePath": "C:\\GoForConf\\data\\snapshot.sqlite",
  "httpAddr": "127.0.0.1:8088",
  "httpAccessEnabled": true,
  "httpAccessFile": "C:\\GoForConf\\config\\http_access.clients.json"
}
```

Создайте файл `config/http_access.clients.json` по пути из `httpAccessFile`. Для запуска reader и адаптера на одном компьютере в списке достаточно адреса `127.0.0.1`.

```json
{
  "version": 1,
  "clients": [{"name": "local-mcp", "ip": "127.0.0.1", "enabled": true}]
}
```

```powershell
.\goforconf-reader.exe --config .\config.local.json serve
```

В конфиге MCP-адаптера, который указан в `GOFORCONF_CONFIG`, задайте `httpAddr` reader и `mcpForbiddenFieldsPath`. Путь к файлу политики полей считается от каталога клиентского JSON. В комплекте можно взять `examples/mcp-client/client.json` и лежащий рядом `mcp_forbidden_fields.md`. При изменении конфигурации перезапустите соответствующий процесс.

Проверка IP у reader включена по умолчанию. Демонстрационный запуск использует `httpAccessEnabled: false` и адрес прослушивания `127.0.0.1:8088`. При отключённой проверке доступ определяется адресом прослушивания и сетевыми правилами. Для работы на разных компьютерах ограничьте подключение к HTTP API доверенными клиентами. HTTP-запросы журналируются. Для явного размещения журналов укажите абсолютный локальный `httpAccessLogDir`.

## Как исследовать конфигурацию

1. Начните с конкретного объекта, действия или симптома. Например, попросите найти точки входа команды «Заполнить» в форме документа и показать код, который устанавливает реквизит.
2. Откройте найденную процедуру через `get_procedure_source` с её `id`. Используйте `trace_procedure` для прямых вызовов и `find_callers` для мест, откуда её вызывают. Сопоставьте базовый код с обработчиками расширений, если они есть в снимке.
3. Отделите наблюдения в коде от условий, которые нужно проверить в самой 1С. Поиск может показать ветку, зависящую от роли, настройки или состояния документа. Уточнить текущее состояние можно через подключённый шлюз данных. [Настройка живой 1С](docs/live-1c.md)

По умолчанию профиль MCP `economy` уменьшает объём результатов первого запроса. Если выдачи мало, укажите нужный `limit` или `depth`, либо передайте `responseProfile: "full"` поддерживающему инструменту. Для всех вызовов профиль задаётся полем `mcpResponseProfile` клиентского JSON. `full` возвращает стандартные лимиты HTTP API. Если `get_object_forms` или `get_object_modules` вернули `hasMore`, передайте `nextProcedureOffset` как `procedureOffset` в следующем запросе.

### Дополнительные возможности

- **Семантический поиск.** Нужен снимок с эмбеддингами и сервис, который принимает запросы к `/v1/embeddings`. На reader укажите `embeddingBaseUrl` и модель `embeddingModel`, соответствующую векторам в снимке. Результаты — кандидаты для дальнейшей проверки по коду.
- **Jira.** Настройте `jiraBaseUrl`, `jiraUser` и `jiraPasswordEnc` на reader. Вызов `get_jira_issue` с `{"key":"DEMO-123"}` возвращает описание, комментарии и сведения о вложениях для указанной задачи. Если комментарии ограничены, в ответе можно проверить `commentsTotal` и `commentsTruncated`.
- **Проверка наложения расширений через HTTP.** Маршрут `/merge/extensions` готовит отчёт по процедурам и диагностике на основе сохранённых слоёв. `/merge/configuration` формирует ZIP с доступным в снимке кодом и XML для проверки. Для этого маршрута требуется настроить `GOFORCONF_MERGE_TOKEN` у reader. [Маршруты HTTP API](cmd/goforconf-reader/generated_http_routes.go)

## Подключение живых данных 1С

Для чтения актуальных записей установите `GoForConfData.cfe` в нужной информационной базе, опубликуйте HTTP-сервис расширения и настройте отдельного пользователя 1С с необходимыми правами чтения. В серверном JSON укажите `oneCDataServiceUrl`, `oneCDataServiceUser` и `oneCDataServicePasswordEnc`. Проверка через MCP начинается с `get_data_service_info`, затем можно описать источник и выполнить ограниченный запрос. [Полный гайд по установке `GoForConfData.cfe` и проверке доступа](docs/live-1c.md)

## Шифрование пароля через `encrypt-data-password`

Откройте интерактивную консоль Windows в каталоге reader и запустите команду.

```powershell
.\goforconf-reader.exe encrypt-data-password
```

Введите пароль по приглашению. Ввод скрыт. Команда принимает пароль через консоль и выводит в стандартный поток одну строку вида `dpapi:<Base64>`. Файл настроек остаётся без изменений.

Скопируйте строку целиком в `oneCDataServicePasswordEnc` серверного JSON. Удалите поле `oneCDataServicePassword` или оставьте его пустым. Для Jira отдельно зашифруйте её пароль и сохраните результат в `jiraPasswordEnc`.

Windows DPAPI привязывает результат к учётной записи Windows. Выполняйте команду на компьютере reader под той же учётной записью, которая запускает reader. При переносе установки на другой компьютер или смене учётной записи заново зашифруйте пароль на целевой установке. Храните результат в локальной конфигурации с ограниченными правами доступа.

## Сборка из исходников

Нужны Windows и Go 1.25 или новее. Запустите тесты и сборку из корня репозитория.

```powershell
go test ./...
go build -trimpath -o goforconf-reader.exe ./cmd/goforconf-reader
go build -trimpath -o goforconf-mcp.exe ./cmd/goforconf-mcp
```

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| `/health` недоступен | Работает ли reader, свободен ли порт и совпадает ли адрес с указанным в конфиге |
| Reader возвращает `403` | Разрешён ли IP клиента в `httpAccessFile` и корректно ли настроена сеть |
| MCP не запускается | Заполнен ли `GOFORCONF_CONFIG`, доступны ли адаптер и файл политики полей, выбран ли `stdio` |
| Объект или процедура не найдены | Точное имя, доступные слои в снимке и его актуальность. При необходимости увеличьте лимит или сузьте поиск до нужного модуля |
| Проверка данных 1С не проходит | Сервис `GoForConfData`, URL публикации, права пользователя и пароль DPAPI. [Диагностика подключения к 1С](docs/live-1c.md#диагностика) |
